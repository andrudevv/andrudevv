# 👋 ¡Hola, soy Andru!


### Sobre mí

Tecnólogo en **Análisis y Desarrollo de Software** con experiencia profesional en desarrollo de aplicaciones empresariales y soluciones de facturación y nómina electrónica integradas con la DIAN.

Mi perfil combina un sólido trabajo en el backend empresarial (Java, Spring Boot, Oracle Database, PL/SQL, Node.js) con el desarrollo frontend en React. Cuento con capacidad analítica, enfoque en la optimización de procesos y una alta disciplina para el aprendizaje autodidacta y la mejora continua.

Actualmente continúo mi formación profesional como **Estudiante de Ingeniería de Sistemas** en la UNAD (7.º semestre) y fortalezco mis habilidades técnicas a través de certificaciones internacionales.

* **Lenguajes:** Java, Python, JavaScript, SQL, PL/SQL

* **Frontend:** React, HTML5, CSS3, JavaScript (ES6+)
* **Bases de Datos:** Oracle Database, Oracle APEX, MySQL
